# Magic Leap 2 CVIP and the original Steam Deck

The Magic Leap 2 build contains a dedicated A55 boot environment, a host PCI driver, interrupt-driven messaging, shared-memory transport, DSP programs and a vision runtime. Seven retail LCD Steam Deck PCI captures omit the endpoint the ML2 driver binds. Two Valve LCD BIOS builds still contain CVIP-aware code. Physical presence and usability on the Deck remain UNKNOWN. [ML2 discovery](../evidence/device-identifiers.md) · [Deck evidence](../analysis/steam-deck-applicability.md)

| What is CVIP, and where is it implemented? | **CONFIRMED.** Magic Leap specifies six Cortex-A55 cores, six vector vision cores and two dedicated ML cores. This release contains A55 boot partitions, four DSP programs, four profiling tables and typed C5/Q6 job maps. Its x86 host driver is built into boot.img. The probe maps resources and configures MSI-X, mailboxes and IOMMU resources. XPC sends short messages via PL320 mailboxes. Shared regions transfer data, and MLNET/NBD supports storage. [Driver match](../evidence/device-identifiers.md) · [Host interface](../analysis/host-interface.md) |

## Driver and compute feasibility

A working port needs a discoverable function, board-supported boot firmware, interrupts, DMA and IOMMU mappings, a shared-memory ABI, compatible DSP images and a submission runtime. The investigation recovered evidence for each software layer on Mero. It found no supported bring-up path or demonstrated accelerator workload on the Deck. The fixed-point rating cannot establish throughput for a new network or an LLM. [Host driver requirements](../analysis/host-interface.md) · [Workload assessment](../analysis/architecture.md)

## Smallest safe test

Run the [read-only collector](../scripts/steam-deck-readonly.sh) on a verified original LCD Deck. It checks the existing PCI inventory, bridge path, resources, firmware identity and available ACPI tables. A positive 1022:149d result would establish an enumerated candidate on that unit. It would still need independent resource and boot-state corroboration. A negative result adds a board/BIOS observation without distinguishing physical absence from disabled hardware. The local LCD Deck also returned zero matches across 30 readable functions. [Local capture](../evidence/deck-live/pci.md) [Interpretation guide](../analysis/steam-deck-applicability.md)
